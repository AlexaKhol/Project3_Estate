# Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

## Контекст и цель проекта
Агентство недвижимости обратилось с запросом на проведение комплексного анализа архива объявлений о продаже жилой недвижимости. 

**Цель проекта:** Провести исследовательский анализ данных и решить ad hoc задачи, чтобы найти самые перспективные сегменты недвижимости в Санкт-Петербурге и Ленинградской области. На основе полученных инсайтов заказчик сможет создать эффективную бизнес-стратегию на рынке, спланировать маркетинговые кампании и выбрать оптимальные сроки для выхода на рынок.

## Основные задачи исследования

### Часть 1. Исследовательский анализ данных 
1. **Временной интервал:** Определение периода, за который представлены данные, для оценки влияния сезонных факторов и динамики показателей.
2. **Типы населённых пунктов:** Анализ распределения объявлений по типам населённых пунктов (от крупных городов до деревень). Важно: Санкт-Петербург и Ленинградская область — это два разных субъекта.
3. **Время активности объявления:** Изучение длительности нахождения объявлений на сайте (дней экспозиции) для прогнозирования среднего времени продажи недвижимости.
4. **Доля снятых с публикации объявлений:** Расчёт процента снятых объявлений (в рамках проекта считается процентом проданных объектов).
5. **Соотношение рынков:** Оценка доли объявлений в Санкт-Петербурге против Ленинградской области для понимания необходимости их раздельного изучения.
6. **Стоимость квадратного метра:** Расчёт и проверка стоимости 1 кв.м. на наличие ошибок и выбросов.
7. **Статистические показатели:** Изучение категориальных и количественных параметров недвижимости.

### Часть 2. Решение ad-hoc задач
1. **Наиболее привлекательные сегменты недвижимости:** Определение сегментов в СПб и ЛО, которые продаются быстрее всего (на основе времени активности объявлений), для создания эффективной бизнес-стратегии.
2. **Сезонные тенденции:** Анализ периодов с повышенной активностью продавцов и покупателей недвижимости для выбора лучших сроков запуска маркетинговых кампаний.

## Структура данных
Архив данных представлен четырьмя таблицами: `advertisement`, `flats`, `city` и `type`.

### Таблица `advertisement` (Объявления)
| Столбец | Тип | Описание |
| :--- | :--- | :--- |
| `id` | int4 (PK) | Идентификатор объявления |
| `first_day_exposition` | date | Дата подачи объявления |
| `days_exposition` | float4 | Длительность нахождения на сайте (в днях) |
| `last_price` | float4 | Стоимость квартиры, руб. |

### Таблица `flats` (Квартиры)
| Столбец | Тип | Описание |
| :--- | :--- | :--- |
| `id` | int4 (PK, FK) | Идентификатор квартиры (связан с `advertisement.id`) |
| `city_id` | varchar | Идентификатор города (FK к `city.city_id`) |
| `type_id` | varchar | Идентификатор типа НП (FK к `type.type_id`) |
| `total_area` | float4 | Общая площадь, кв.м. |
| `rooms` | int4 | Число комнат |
| `ceiling_height` | float4 | Высота потолка, м. |
| `floors_total` | float4 | Этажность дома |
| `living_area` | float4 | Жилая площадь, кв.м. |
| `floor` | int4 | Этаж квартиры |
| `is_apartment` | int4 | 1 — апартаменты, 0 — нет |
| `open_plan` | int4 | 1 — открытая планировка, 0 — нет |
| `kitchen_area` | float4 | Площадь кухни, кв.м. |
| `balcony` | float4 | Количество балконов |
| `airports_nearest` | float4 | Расстояние до аэропорта, м. |
| `parks_around3000` | float4 | Число парков в радиусе 3 км |
| `ponds_around3000` | float4 | Число водоемов в радиусе 3 км |

### Таблица `city` (Города)
| Столбец | Тип | Описание |
| :--- | :--- | :--- |
| `city_id` | varchar (PK) | Идентификатор населенного пункта |
| `city` | varchar | Название населенного пункта |

### Таблица `type` (Типы населенных пунктов)
| Столбец | Тип | Описание |
| :--- | :--- | :--- |
| `type_id` | varchar (PK) | Идентификатор типа населенного пункта |
| `type` | varchar | Название типа населенного пункта |
